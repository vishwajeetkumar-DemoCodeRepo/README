## Current open source work

I recently reviewed [Don't Be Michael](https://github.com/agentvivekkumar/dontbemichael), a local multi agent office application.

One enhancement I proposed is a **Unified Action Gateway**. The idea is to give important external actions one common approval and execution path, so an agent can prepare work freely but consequential actions can be reviewed, approved and audited before they happen.
